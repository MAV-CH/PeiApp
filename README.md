# Pei — анализ пайки
Десктопное приложение на PySide6 для автоматической детекции эпизодов пайки на видео с помощью обученной модели машинного обучения.

## Назначение
Приложение загружает видеофайл, прогоняет его через модель и отображает найденные участки пайки на интерактивном таймлайне. Позволяет воспроизводить видео, перематывать, просматривать статистику по найденным эпизодам.

## Будущее
- Приложение разработано на PySide6 и является кросс-платформенным. Оно будет иметь 3 бинарных файла, для: Windows, Linux, MacOS.
- UI, в процессе разработки будет редактироваться.
- Код будет дорабатываться и переписываться.
#### Дополнительно*
- Будет доступна функция подключения различных моделей для извлечения статистики через них. В данном случае проект будет переименован.
- Будет добавлена локальная база данных(SQLite) для хранения истории статистики.
- Приложение будет переделано:
    1. Добавлено окно авторизации.
    2. База данных будет реализована на облачном сервере с использованием PostgreSQL

## Примечание
- SPP.
- Модель обучается в отдельном проекте.
- Видео данные конфиденциальны, поэтому они не будут доступны в открытом доступе для тестирования.
- Приложение делается под модель, не наоборот.
- Базы данных в проекте не используются
