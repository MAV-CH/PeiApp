# Pei — анализ пайки

Десктопное приложение на PySide6 для автоматической детекции эпизодов пайки на видео с помощью обученной модели машинного обучения.

## Назначение

Приложение загружает видеофайл, прогоняет его через модель и отображает найденные участки пайки на интерактивном таймлайне. Позволяет воспроизводить видео, перематывать, просматривать статистику по найденным эпизодам.
